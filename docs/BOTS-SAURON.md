# Bots: Sauron — doctrine dossier

The reference doc for what Sauron (plain and hardcore) actually does, as coded — not as the
docblocks *say* he does. Top level, deliberately: `doc-rot-scan.mjs` only reads top-level
`docs/*.md` (a subdirectory doc is enforced by nothing), and an unenforced call sheet is exactly
what rots. Two parts: a **doctrine call sheet** (this persona's coded rules, graded honestly) and
an **adaptation ledger** (append-only — every real change to that doctrine, going forward, gets a
row here; never edit a past row). PR 8's doctrine-scan loop reads the ledger table below and flags
`Next check` dates that have passed with nothing appended to resolve them.

Honest grade throughout is **low** — most rows are verified against code, not against outcomes; no
backtest or live-P&L review sits behind most of these calls yet.

## Open unknowns

Two things this doc states rather than asserts, because the repo alone can't settle them:

- **Whether hardcore mode is currently armed.** `fly.bots.toml`'s checked-in `[env]` block does not
  set `SKYNET_HARDCORE_BOTS` at all — `run-autonomous.ts`'s own docblock claims "Currently: sauron,"
  but that's a comment in code, not a live read of the deployed process. Per that same docblock,
  hardcore is "flip[ped] via autonomy-ops only," which sets a Fly secret; a Fly secret of the same
  name outranks `[env]` and is invisible from this repo. This doc cannot say whether hardcore is
  armed right now.
- **Whether Sauron has ever traded live, beyond today.** The repo's checked-in default is
  `SKYNET_AUTONOMOUS_MODE = "observe"` (decide + log, place nothing) — but as with the hardcore
  flag, a Fly secret can override this and would not show up here. Separately from the repo: account-
  activity screenshots reviewed earlier in this session, today (2026-09-22), showed real filled
  trades with real P&L (AMZN, MRVL, TSLA, GOOGL, META) — so Sauron has traded live at least as of
  today. This doc does not claim more than that: not whether those fills were plain or hardcore
  Sauron, not how long live mode has been on, and not whether it is still on now.
