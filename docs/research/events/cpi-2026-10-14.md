**Amendment 2026-08-31 — the asymmetry narrowed (receipt: the D-44 row).** The direction of the
stance is unchanged (stand aside; no action licensable), but its *mechanism* is amended. Warsh's
2026-08-28 Jackson Hole keynote pinned the hawkish case on **PCE** — 3.7% 12-month, 4.1% 6-month —
while judging labour "quite stable" and financial conditions accommodative, and nearly doubled
September hike odds in one session. Core PCE runs roughly **100bp above core CPI** (Cleveland Fed,
2026-08-28: Aug core CPI 2.38% y/y vs core PCE 3.40% y/y), so the index this doc's map keys on is
*not* the index the chair is arguing from. Consequence: **the cool-core relief leg is downgraded**
— a soft core CPI has to overcome the chair's own framing before it can move the path — while the
**hot-core tail is unchanged**, because a hot core CPI simply corroborates him. The payoff is now
asymmetric the *other* way from the initial read: less upside on a cool print, same downside on a
hot one.

**Amendment 2026-08-31 — kill switch 4 is inverted, not fired.** It anticipated a 09-16 FOMC
pre-commitment *shrinking* this print's surprise power. Warsh instead **formally abandoned forward
guidance** ("a discipline, not a decision"). With no guidance to anchor to, each incoming print
carries *more* surprise power into the 10-27/28 FOMC, not less — so the reassessment priority on
this event is raised, not downgraded. The switch is restated below to match.

**Kill switches for the working read:**

  this switch's *precondition* no longer holds by default — a re-adoption of explicit guidance at
