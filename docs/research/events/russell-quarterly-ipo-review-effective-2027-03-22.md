   every effective open a Monday. March 2027's third Friday is **2027-03-19**, so the effective open is

   date was *printed in the document*. **The string "2027" does not appear anywhere in the FAQ.** So the
   `estimate` label here carries more weight than the sibling's did — it is not merely a prefix gap.

2. **The sibling's stated reason for the null is wrong: this is not an IPO-adds-only event — REFUTED, from the
   owner's own words.** The September ledger's signal list reads *"Scope is small by construction — IPO adds
   only, from the 1 May–31 July 2026 window; no cap-tier migration, no style re-scoring, no float

   across existing constituents**, and the Russell US Style capping recap struck at the review cut-off. That is
   a whole-index re-weighting mechanic, not a handful of new lines. **This does not change the call — it makes
   the null stronger**, because a bigger mechanism producing the same nothing is better evidence than a small
   one producing nothing. It matters to the next reader who might be tempted to size the flow from that
   sentence.

sign, not a demonstration that its flow is zero. **The dose-response argument assumes only an ordering.** It
needs June reconstitution flow to exceed quarterly review flow, which the owner's own parallel-run turnover
figure supports, but no turnover figure for a quarterly leg could be sourced — "roughly a twentieth" is a
scope inference, not a measured ratio, and the argument would survive a wide error on it but is not a
regression. **The instrument is near-blind, re-measured here.** June reconstitution moves IWM's relative
turnover to 1.129× against a 1.044× baseline, so every turnover null in this family measures a floor with a
